# Tactical prototype audio

All files in this folder are used as placeholder/prototype SFX and are licensed CC0 1.0.

- `Gunshot_01.wav`–`Gunshot_03.wav`: edited public-domain firearm reports distributed by the Hard Lines project. Source documentation: https://github.com/yegors/hard-lines/blob/main/public/audio/README.md
- `Round_Start.wav`, `Round_Win.wav`, `Hit_Confirm.wav`, `Damage_Taken.wav`, `UI_Select.wav`: Kenney Interface Sounds. Source: https://kenney.nl/assets/interface-sounds

Attribution is not required by CC0, but the source information is preserved here for auditing.
